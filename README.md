# Fader project — прототип

```
fader-project/
  fader-ui/       интерфейс с фейдером (TypeScript + React + Vite)
  fader-server/   тестовый сервер (Node.js + TypeScript + Express + ws), работает с платой по USB
  firmware/       тестовая прошивка для Arduino / ESP32
  scripts/dev.mjs запуск обоих одной командой
```

## Что нужно один раз

Node.js версии 20 или новее: https://nodejs.org (LTS). Проверка в терминале: `node -v`

## Запуск в VS Code

1. Распаковать архив, в VS Code: **File → Open Folder…** → выбрать папку `fader-project`.
2. Открыть терминал: **Terminal → New Terminal** (или Ctrl+`).
3. Установить зависимости (только первый раз, ~1 минута):
   ```bash
   npm install
   ```
4. Запустить сервер и интерфейс:
   ```bash
   npm run dev
   ```
5. Открыть в браузере http://localhost:5173 → нажать **«Подключить»** → двигать фейдер.

Остановить — **Ctrl+C** в терминале.

Плата с фейдером (Arduino / ESP32) подключается по USB к этому же компьютеру и выбирается в интерфейсе, в панели «Устройство». Прошивка и проверка — в `firmware/README.md`. Без платы можно выбрать «Имитация».

Логи сервера и интерфейса идут в один терминал с метками `[server]` и `[ui]`.
Страница статуса сервера (значение фейдера вживую): http://localhost:8765

## Другие команды (из корня)

| команда              | что делает                          |
|----------------------|-------------------------------------|
| `npm run dev`        | сервер + интерфейс вместе            |
| `npm run phone`      | то же, но интерфейс в обычной (не отладочной) сборке — для телефона, http://localhost:4173 |
| `npm run dev:server` | только сервер                        |
| `npm run dev:ui`     | только интерфейс                     |
| `npm run typecheck`  | проверка типов в обоих проектах      |
| `npm test`           | тесты сервера (разбор MIDI, работа с устройством) |

В VS Code то же есть через **Terminal → Run Task…** («Установить зависимости», «Запустить всё»).

## Если что-то не так

- **`npm : Невозможно загрузить файл ... npm.ps1`** (Windows PowerShell) — выполнить один раз
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и перезапустить терминал. Или переключить терминал на Command Prompt (стрелка рядом с «+» в панели терминала).
- **`Порт 8765 занят`** — уже запущен другой сервер (например, во втором терминале). Закрыть его или в `fader-server` запустить `PORT=8766 npm run dev` и поменять адрес в интерфейсе.
- **Во фронте «Соединение закрыто: код 1006»** — сервер не запущен или адрес в поле неверный (должен быть `ws://localhost:8765`).
- **С телефона** — сервер при запуске печатает адрес в сети (`ws://192.168.x.x:8765`), интерфейс открывается по `http://192.168.x.x:5173`. Устройства должны быть в одной Wi-Fi сети.

Подробности — в `fader-ui/README.md` и `fader-server/README.md`.
